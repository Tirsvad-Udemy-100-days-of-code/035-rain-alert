# Bidrag

Dette repository bruger SQA- og QC-frameworket i `framework/`.

1. Intet kommer under `src/` eller `tests/`, før den milepæl, der indeholder opgaven, er accepteret med et `Go`-review (`docs/milestones/`).
2. Arbejd på én gren pr. milepæl, én pull request pr. milepæl, og luk de issues, den afslutter, med én `Closes #N`-linje hver.
3. Review koden mod Python-tjeklisten (`QC-PY-001`) og registrér det i `docs/sqa/reviews/`.
4. En anden end forfatteren fletter pull requesten.

Reglerne for AI-agenter står i `AGENTS.md`. Læg aldrig `config.env` eller `.env` i git.
