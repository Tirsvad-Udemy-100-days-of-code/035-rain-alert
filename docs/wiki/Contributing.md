# Contributing

This repository uses the SQA and QC framework in `framework/`.

1. Nothing goes under `src/` or `tests/` before the milestone that contains the task is accepted with a `Go` review (`docs/milestones/`).
2. Work on a branch per milestone, one pull request per milestone, and close the issues it finishes with one `Closes #N` line each.
3. Review the code against the Python checklist (`QC-PY-001`) and record it in `docs/sqa/reviews/`.
4. A reviewer other than the author merges the pull request.

The rules for AI agents are in `AGENTS.md`. Never commit `config.env` or `.env`.
